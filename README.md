# Code1Line | Sistema de Avaliação de Desempenho

![Status](https://img.shields.io/badge/status-concluído-brightgreen)
![Linguagem](https://img.shields.io/badge/linguagem-C%23-blue)
![Banco de Dados](https://img.shields.io/badge/Banco%20de%20Dados-SQL%20Server-orange)

O **Code1Line** é uma aplicação robusta desenvolvida para a **gestão e avaliação de desempenho profissional**.  
O projeto foca na organização de funcionalidades e em uma **estrutura eficiente de tarefas**, permitindo o acompanhamento detalhado de métricas de produtividade.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com tecnologias modernas de **back-end** e gerenciamento de dados:

- **Linguagem:** C#  
- **Banco de Dados:** Microsoft SQL Server (armazenamento estruturado e seguro)  
- **Integração:** Lógica de integração entre a aplicação e a camada de dados  

---

## 📋 Funcionalidades Principais

- **Gerenciamento de Avaliações:** Estrutura completa para registrar e consultar o desempenho profissional  
- **Organização de Tarefas:** Sistema hierárquico para divisão e acompanhamento de metas  
- **Integração de Dados:** Persistência garantida através da conexão direta com SQL Server  

---

## 🛠️ Competências Aplicadas

Durante o desenvolvimento do projeto, foram aplicadas as seguintes habilidades técnicas:

- **Lógica de Programação:** Estruturação de algoritmos eficientes em C#  
- **Versionamento:** Controle de alterações e colaboração utilizando Git e GitHub  
- **Metodologias Ágeis:** Planejamento de sprints e organização de tarefas seguindo o framework Scrum
